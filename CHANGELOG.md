# Список изменений

English: [CHANGELOG.en.md](CHANGELOG.en.md)

## 0.1.0 — первая открытая версия

- **Архив.** Каталог архива с корпусом и индексом; поиск по смыслу и по словам из командной строки, со страницы и по сети.
- **Доступ.** Токены с уровнями «чтение» и «полный», журнал обращений, шлюз в частную сеть, подписанные ссылки на документы.
- **Приёмка.** Входящая папка, определение типа по содержимому, правила безопасности, сверка с уже принятым, проверка
  локальной моделью, очередь утверждения, карантин, папка возврата, квитанции по каждому файлу. Ничего не теряется: не принятое возвращается в папку возврата, а убираются только
  точные копии сохранённого, пустые файлы и следы систем (`__MACOSX`, `.DS_Store`); судьбу служебных файлов по шаблонам имён задаёт `service_fate`.
- **Модели.** Протокол MCP и восемь инструментов: поиск, чтение документов, схемы, графики, сборка файлов, передача документа
  в архив. Локальная модель — любой сервер с интерфейсом OpenAI; запасная облачная модель берёт ключ из `FLYARCHIVE_LLM_CLOUD_KEY` или из файла. Оболочки внешних моделей запускаются
  в песочнице. PDF с русским текстом собирается шрифтом с кириллицей (его можно задать настройкой `pdf_font`).
- **Просмотр и описание.** Страницы документов картинками (рабочий процесс идёт настоящим интерпретатором родителя); описание картинок и сканов локальной моделью со зрением.
- **Оболочка.** Плагин для DeepSeek Harness: вкладка и раздел «Archive».
- **Установка.** Одна команда из шаблонов; поставленная команда идёт интерпретатором установки через запускалку. Проверка окружения, которая пробует и песочницу, файлы зависимостей,
  образцы и сценарий «первые пять минут».
