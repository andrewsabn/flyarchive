# Узлы, на которые разрешены ссылки в открытом репозитории (ворота публикации, tests/publication_gate.py).
# Строка: узел | причина.  «*.узел» — любой поддомен; без звёздочки только сам узел.
# Строка без причины не принимается и сама становится находкой. Ссылка на узел, которого здесь нет, — находка.
# Сюда идут узлы, на которые ссылка уместна в любом файле; образцы в одном тесте снимает файл исключений publication_allow.txt.
www.w3.org | пространства имён XML (SVG, XHTML): идентификаторы, а не ссылки
schemas.openxmlformats.org | пространства имён Office Open XML в образцах файлов
www.omg.org | пространство имён BPMN в образце схемы
fsf.org | текст лицензии AGPL-3.0 в файле LICENSE: адрес издателя лицензии, текст приводится дословно
www.gnu.org | текст лицензии AGPL-3.0 в файле LICENSE: ссылки на страницу лицензий, текст приводится дословно
ollama.com | сайт проекта Ollama: страница загрузки службы векторов, на неё ссылаются README и документ эксплуатации
github.com | адрес открытого репозитория проекта: команда клонирования в README
